# Don't Starve Food Guide

An unofficial food reference, Crock Pot simulator, and recipe discovery tool for
Don't Starve, Don't Starve Together, and supported DLCs and characters.

- [Use the live guide](https://foodguide.bluehexagons.com) or the [GitHub Pages guide](https://bluehexagons.github.io/foodguide/).
- [Download the desktop app](https://github.com/bluehexagons/foodguide-app/releases).
- [Learn how to use the guide](docs/usage.md).
- [Report a bug or request a feature](https://github.com/bluehexagons/foodguide/issues).

The guide stores your inventories and cookbook on your device. Use Options to export
or import a backup.
